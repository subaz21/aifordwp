# FinBridge Copilot Prompting Starter Guide

Audience: Non-technical office staff
Purpose: Help you get better results from Microsoft 365 Copilot in everyday work

## The Easy Prompt Formula (Use Every Time)
Use this 4-part formula:

Task + Context + Output + Limits

What each part means:
- Task: What you want Copilot to do
- Context: Where the information is (email thread, document, worksheet, date range)
- Output: How you want the answer (bullets, table, draft email, action list)
- Limits: Tone, length, audience, deadline

Reusable template:
"Please [task] using [context]. Return as [output]. Keep it [limits]."

Quick example:
"Please summarise the Q3 budget email thread from this week. Return as 5 bullet points with decisions, owners, and deadlines. Keep it concise for a leadership update."

## Outlook: Real Prompt Examples

### 1) Catch up quickly after time away
"Summarise my unread emails from the last 3 working days. Group into urgent, waiting for my reply, and for information only. For urgent items, include sender, subject, and the action I need to take today."

### 2) Draft a clear professional reply
"Draft a reply to this thread confirming we can send the revised finance report by Friday at 3 PM. Include 3 action points and one question to confirm scope. Keep it polite and under 140 words."

### 3) Build a meeting brief from an email chain
"From this email conversation, create a short meeting brief with: key issue, decisions made, open questions, risks, and who owns each action. Return in bullet points."

## Word: Real Prompt Examples

### 1) Rewrite in plain English
"Rewrite this draft policy update in plain English for non-technical staff. Keep the meaning the same, reduce jargon, and format with headings and bullet points."

### 2) Create an executive summary
"Create a one-page executive summary from this document for senior leadership. Include purpose, top 3 findings, business impact, and recommended next steps."

### 3) Turn notes into a formal update
"Turn these rough notes into a professional meeting summary with sections: Background, Discussion, Decisions, Actions, and Owners. Keep it ready to share with Finance leadership."

## Excel: Real Prompt Examples

### 1) Find trends and unusual values
"Review this worksheet and identify monthly spending patterns and any unusually high or low numbers. Return a table with category, month, change from the previous month, and a plain-English explanation of what changed."

### 2) Produce a manager-ready summary
"Create a short summary for a department manager. Include top 5 cost categories, largest month-on-month increase, and one recommendation to control spend next month."

### 3) Run a quick data quality check
"Scan this table for missing values, duplicate rows, and inconsistent date formats. Return a checklist of issues and suggested fixes in priority order."

## Make Your Prompt Better in 10 Seconds
- Name the exact source: "this thread", "this file", "this worksheet", or a date range.
- Ask for a format: bullets, table, draft email, or action list.
- Set simple limits: who it is for, how long, and tone.
- If answer is too generic, add a follow-up: "Use more detail from this file and include exact action owners."

## Day 1 Data-Safety Habit (Important)
You can use Microsoft 365 Copilot confidently for day-to-day work in company-approved systems.

Keep the Day 1 safety habit: do not paste confidential client data, payroll details, board packs, M&A information, passwords, or personal data into external public AI tools. If you are not sure whether a tool is approved, pause and check with IT/Security first.

## If Copilot Output Looks Wrong
- If Copilot says it cannot access a file, first check you can open the file directly.
- If answers are too generic, add clearer context and required output format.
- If content is very new, wait a short time and try again.
- If still blocked, contact Service Desk with app name, time, and screenshot/error text.
