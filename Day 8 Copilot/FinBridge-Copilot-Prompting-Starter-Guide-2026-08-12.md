# FinBridge Copilot Prompting Starter Guide

Audience: Non-technical office staff
Purpose: Help you get better results from Microsoft 365 Copilot in daily work

## Start Here: The 1-Line Prompt Formula
Use this simple pattern every time:

Task + Context + Output + Limits

What this means in plain English:
- Task: What you want Copilot to do
- Context: Where the information is (email thread, document, spreadsheet, date range)
- Output: How you want the answer presented (bullets, table, draft email)
- Limits: Any boundaries (length, tone, audience, deadline)

Quick reusable template:
"Please [task] using [context]. Return as [output]. Keep it [limits]."

Example:
"Please summarise the email thread about Q3 budget approvals from this week. Return as 5 bullet points with decisions, owners, and deadlines. Keep it concise and suitable for leadership update notes."

## Outlook: Ready-to-Use Prompts

### Example 1: Inbox catch-up after leave
"Summarise my unread emails from the last 3 working days. Group by urgent, waiting for my reply, and FYI. For urgent items, include sender, subject, and the action I need to take today."

### Example 2: Draft a reply with clear actions
"Draft a reply to this email thread confirming we can deliver the revised finance report by Friday 3 PM. Include 3 action points, a polite tone, and one question to confirm final scope. Keep it under 140 words."

### Example 3: Meeting prep from email chain
"From this email conversation, create a short pre-meeting brief with: key issue, decisions already made, open questions, and risks. Return as bullet points I can paste into Teams chat."

## Word: Ready-to-Use Prompts

### Example 1: Improve clarity of a draft
"Rewrite this draft policy update in plain English for non-technical staff. Keep the meaning the same, reduce jargon, and keep the final version under one page with headings and bullet points."

### Example 2: Executive summary for leaders
"Create a one-page executive summary from this document for senior leadership. Include purpose, top 3 findings, business impact, and recommended next steps. Use short paragraphs and clear headings."

### Example 3: Convert notes into a formal document
"Turn these rough notes into a professional meeting summary with sections: Background, Discussion, Decisions, Actions, and Owners. Keep the tone formal and ready to share with Finance leadership."

## Excel: Ready-to-Use Prompts

### Example 1: Spot trends and outliers
"Review this worksheet and identify monthly spending trends and unusual outliers. Return a table with category, month, variance, and a plain-English explanation of what changed."

### Example 2: Build a management summary
"Create a short summary of this data for a department manager. Include top 5 cost categories, largest month-on-month increase, and one recommendation to control spend next month."

### Example 3: Check data quality
"Scan this table for missing values, duplicate entries, and inconsistent date formats. Return a checklist of issues found and suggested fixes in priority order."

## Tips That Improve Results Fast
- Be specific about the source: "this thread," "this document," "this worksheet," or a date range.
- Ask for a format: bullets, table, draft email, action list.
- Set limits: tone, length, audience, deadline.
- If the first answer is too generic, ask a follow-up: "Use more detail from the attached document and include exact action owners."

## Data Safety Habit (From Day 1)
Use Microsoft 365 Copilot for work content inside approved company systems.

Do not paste confidential client data, payroll data, board packs, M&A details, passwords, or personal data into external public AI tools. If you are unsure whether a tool is approved, stop and check with IT/Security first.

## Quick Troubleshooting (When Output Looks Wrong)
- If Copilot says it cannot access a file, check you can open it directly first.
- If answers are too generic, add clearer context and output format.
- If content is very new, wait a short time and try again.
- If still blocked, contact Service Desk with the app name, time, and a screenshot/error text.

## One-Minute Prompt Builder
Before sending your prompt, check:
- Did I clearly state the task?
- Did I mention the exact context/source?
- Did I ask for a specific output format?
- Did I set length/tone/audience limits?
- Is my data handling safe and compliant?
