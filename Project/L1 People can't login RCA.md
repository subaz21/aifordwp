# L1 People can't login RCA

If you cannot log in, or login is very slow on Floor 6, use this quick guide.

1. Try once more and note the exact time.
2. If it still fails, do not keep retrying many times.
3. Raise a high-priority Service Desk ticket and include:
- Your full username
- Device name
- Time of failed attempt
- Error message or screenshot
4. If available, try an approved backup device or location.
5. Stay reachable for an IT callback.

What IT will do:
- Check sign-in logs and error code.
- Confirm if this is policy, compliance, MFA, or service related.
- Apply a safe, temporary fix for affected users if needed.

When to call it urgent:
- You cannot log in at all.
- Multiple nearby users have the same issue.
- You are blocked from critical work.

Ticket reference: Floor 6 Multi-user Login Failure/Latency.
